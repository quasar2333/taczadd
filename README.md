## 宝石镶嵌系统

### 基础介绍

宝石镶嵌是本模组的核心玩法。你可以将各种宝石镶嵌到**枪械**或**装备（盔甲）**上，为它们提供强力的属性加成。

### 如何打开宝石镶嵌界面

按下设置的快捷键（默认需要在控制选项中设置）即可打开**宝石镶嵌**界面。

### 宝石鉴定

新获得的宝石显示为 **"（未鉴定）"** 状态，需要使用 **宝石鉴定器** 进行鉴定后才能显示具体的属性数值。未鉴定的宝石可以镶嵌，但无法看到确切效果。

### 宝石插槽

- 使用 **插槽解锁器** 可以为枪械或装备解锁额外的宝石插槽
- 按住 **Shift** 键查看物品可以显示详细的宝石效果信息

## 强化系统

强化系统可以让你的枪械和装备变得更加强力。

### 强化水晶类型

| 物品名称 | 使用范围 | 强化等级 | 每级效果 |
|---------|---------|---------|---------|
| **次级枪械强化水晶** | 枪械 | 0~12级 | 基础伤害+15% |
| **中级枪械强化水晶** | 枪械 | 13~19级 | 基础伤害+20% |
| **次级装备强化水晶** | 盔甲 | 0~12级 | 伤害减免+1 或 枪械伤害+5% |
| **中级装备强化水晶** | 盔甲 | 13~19级 | 伤害减免+2 或 枪械伤害+10% |

### 如何强化

1. **右键点击**强化水晶打开强化界面
2. 将要强化的**枪械**或**装备**放入槽位
3. 点击**强化**按钮进行强化

### 强化概率

强化有一定的失败概率，等级越高失败率越高：

| 强化等级 | 成功率 | 保底次数 |
|---------|-------|---------|
| 0级 → 1级 | 100% | 1次 |
| 1级 → 2级 | 50% | 2次 |
| 2级 → 3级 | 25% | 4次 |
| 3级 → 4级 | 12% | 8次 |
| 4级 → 5级 | 6% | 16次 |
| 5级 → 6级 | 3% | 32次 |
| 6级 → 7级 | 1.5% | 64次 |
| 7级 → 8级 | 1% | 128次 |
| 8级 → 9级 | 0.5% | 256次 |
| 9级 → 10级 | 0.2% | 256次 |
| 10级 → 11级 | 0.1% | 512次 |
| 11级 → 12级 | 0.05% | 1024次 |
| 12级 → 13级 | 0.025% | 2048次 |

> **保底机制**：每次强化失败会累计保底进度，达到保底次数后**必定成功**！

### 装备强化方向

装备强化时有50%概率增加**伤害减免**，50%概率增加**枪械伤害**。使用**装备诱导器**可以改变这个概率。

## 装备诱导器

**装备诱导器**是一种稀有道具，可以"诱导"装备的强化方向。

### 使用方法

1. 右键点击**装备诱导器**打开诱导界面
2. 将要诱导的**装备**或**枪械**放入槽位
3. 点击**诱导**按钮

### 效果

- 诱导成功率：**1%**
- 诱导成功后，该装备在之后的强化中有**90%的概率**增加**枪械伤害**，而不是原本的50%概率

> 诱导器可通过副本获得，可交易。

## 枪械进阶系统

进阶系统允许你将基础枪械升级为更强大的特殊枪械，同时**保留**所有的强化等级、宝石效果等数据。

### 进阶核心列表

| 核心名称 | 前置枪械 | 目标枪械 |
|---------|---------|---------|
| **AK47共鸣-AK24特种部队进阶核心** | AK47 "共鸣" | AK24 "特种部队" |
| **AK24特种部队-AK47破战者进阶核心** | AK24 "特种部队" | AK47 "破战者" |
| **M4末影龙核心** | AUG "失落的海盗船" | M4A1 "末影龙" |
| **M4末影龙-H4醉迷之音进阶核心** | M4A1 "末影龙" | H4 Blixen "醉迷之音" |
| **SG914-K30进阶核心** | SG914 | K30 |

### 如何使用进阶核心

#### 第一步：激活核心

新获得的进阶核心处于 **"（未激活）"** 状态，需要先激活才能使用。

1. **右键点击**未激活的进阶核心，打开**激活界面**
2. 放入 **20个通用枪械进阶模块**
3. 点击**激活**按钮

激活成功后，核心会发光（附魔效果）。

#### 第二步：升级枪械

1. **右键点击**已激活的进阶核心，打开**升级界面**
2. 将对应的**前置枪械**放入槽位
3. 点击**升级**按钮

升级成功后会获得目标枪械，原枪械的所有数据（强化等级、宝石效果、击杀数等）都会保留。

## 常见问题

### Q: 如何获得宝石和强化材料？

A: 宝石和强化材料的获取方式取决于服务器配置，通常通过副本掉落、商店购买或特殊活动获得。

### Q: 强化失败会掉等级吗？

A: 不会！强化失败只是本次强化没有成功，不会降低现有等级，且会累计保底进度。

### Q: 进阶后的枪械数据会丢失吗？

A: 不会！进阶会保留原枪械的所有数据，包括强化等级、宝石效果、击杀数等。

### Q: 枪械名称后面的 +数字 是什么意思？

A: 那是枪械的强化等级。例如 "AK47 +5" 表示这把枪已经强化到5级。

### Q: 如何查看枪械的详细属性？

A: 按住 **Shift** 键查看物品，可以看到完整的属性面板，包括宝石效果、伤害倍率等。
